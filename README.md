# ChatGPT Clone

A web-based AI chat application where users can create an account, sign in, and
ask questions. The app uses Google Gemini to generate responses and keeps each
user's conversations private to their account.

## Features

- User registration and login
- AI-powered question and answer chat
- Conversation history for signed-in users
- Responsive interface for desktop and mobile
- Formatted responses, including Markdown

## Built with

- React
- Express and Node.js
- MySQL
- Google Gemini API
